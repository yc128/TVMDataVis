## Project Overview
Welcome to the development documentation for the TVM Data Visualization Tool! 
This project is designed to provide a comprehensive and user-friendly interface for visualizing performance metrics generated by TornadoVM's various benchmarks, 
 The tool aims to facilitate the analysis of different devices' performance across multiple runs, 
enabling developers and researchers to gain insights into the efficiency and speedup of their systems from charts.

### Key Features
* **Performance Visualization:** Allows users to compare performance metrics across different devices or runs, with support for custom parameters.
* **Interactive Charts:** Features dynamic chart generation with options for grayscale display, data annotation, and raw data visualization.
* **Data Export:** Users can download generated charts as images or PDF files for further analysis or reporting.


### Technology Stack
* **Programming Language:** Python for backend data processing and JavaScript for frontend interactivity.
* **Framework:** Django serves as the backend framework, handling data management and providing APIs for the frontend.
* **Database:** The project uses Django ORM for database interactions, with data stored in an SQLite3 database.
* **Frontend Libraries:** Google Charts is used for rendering interactive charts, with HTML, CSS, and JavaScript (including libraries like jsPDF) managing the user interface and functionality.

## Project Structure

This section provides an overview of the project structure for the **TVM Data Visualization Tool**.

### Root Directory
- **`manage.py`**: Django's management script for running administrative tasks.

### `/TVMDataVis` Directory
Contains the main Django project configuration.
- **`settings.py`**: Project settings and configurations.
- **`urls.py`**: URL routing for the project.
- **`wsgi.py`/`asgi.py`**: Entry points for WSGI/ASGI servers.

### `/tvmvis` Directory
The core application directory containing the main app logic.
- **`models.py`**: Database models.
- **`views.py`**: Application views.
- **`urls.py`**: URL routing specific to the app.
- **`static/tvmvis`**: Static files such as JavaScript, CSS.
- **`templates/tvmvis`**: HTML templates for rendering views.

### `/tvmvis/chart_data_manager` Directory
Handles data loading and processing for chart visualization.
- **`chart_data_loader.py`**: General data loader for charts.
- **`speedup_chart_data_loader.py`**: Specialized loader for speedup charts.

### `/tvmvis/data_manager` Directory
Contains scripts for managing and processing benchmark data.

- **`benchmark_table_builder.py`**: Builds benchmark tables.
- **`command_line_io.py`**: Handles command-line interactions, running commands and capturing their outputs.
- **`data_reader_main.py`**: The main script responsible for reading and processing data from profiler outputs and command outputs.
- **`hardware_info_fetcher.py`**: Fetches hardware-related information by output of command `clinfo`.
- **`profiler_reader.py`**: Specializes in reading and interpreting profiler data, converting it into a usable format.
- **`result_builder.py`**: Constructs results tables from processed profiler data.
- **`run_table_fetcher.py`**: Build Run tables, fetching such as timestamps and commit points by commands, then store into the database.
- **`version_fetcher.py`**: Retrieves version information for various software components.


### Goals and Future Development

#### 1. **Data Reader Enhancements**
   - **Objective**: Ensure robust and accurate data extraction in the `data_reader`.
   - **Action Items**:
     - **Testing and Debugging**: Thoroughly test and modify the code in `run_table_fetcher` to ensure that it correctly reads the output from the `tornado --version` command and store version and commit point into Run table correctly.

#### 2. **Baseline Functionality**
   - **Objective**: Introduce a baseline comparison feature to enhance the analytical capabilities of the tool.
   - **Action Items**:
     - **Baseline Selection**: Allow users to select a specific run or device as a baseline for comparison.
     - **Speedup Calculation**: Implement functionality to calculate and visualize the speedup of other runs or devices relative to the selected baseline.

#### 3. **User Options and Chart Customization**
   - **Objective**: Expand the customization options available to users for generating and viewing charts.
   - **Action Items**:
     - **Additional User Options**: Provide more flexibility by adding options such as advanced filtering.
     - **Chart Types**: Introduce new chart formats and visualizations to accommodate different types of data analysis.
     - **Improved User Interface**: Continuously refine the user interface to make these new options intuitive and accessible.

By focusing on these goals, the project aims to provide more powerful tools for data analysis and visualization, ensuring that users can gain deeper insights into the performance metrics of their benchmarks. These enhancements will also make the tool more versatile and user-friendly, catering to a broader range of analytical needs.
